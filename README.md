# Scopetta

A two-player Scopa game for the browser: one static page, no build step, the
1997 card art from [Discola](https://github.com/diegoami/discola-web), the
table and the tooling from [Tressette](https://github.com/diegoami/Tressette).

Nothing is built yet. `PLAN.md` is the architecture and the plan; iteration 6
rewrites this file properly.
